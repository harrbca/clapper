# ray-rig (shared style)

A copy of [`ray-rig`](../ray-rig) in the kit's shared style: `"style": {"ink": "#1D1A24", "line": 3.4, "line3d": 3}` in `video.json`, so the 2D and 3D kits draw one ink colour and matching line weights (see style.js in the README). The original keeps its own look. The voice cache is copied, so `clap voice` costs no credits.
