# The cast

The kit's cut-out people, lined up: Dex and the ten made by `tools/make_people.py`. `scenes/index.js` names
them one by one (Callum's voice) and each waves on their name. Lab pages: `lab.js` (everyone, front and
3/4), `lab-turn.js` (every angle; `?group=office` for the office) and `lab-faces.js` (expressions and poses).
